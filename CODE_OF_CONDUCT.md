# Code of conduct

This is a small project about README cards. Keep discussion about the code, the docs and the data.

- Be direct and be decent. Disagree with an idea, not a person.
- No harassment, slurs, or publishing anyone's private details.
- No shilling. Issues and pull requests are not the place to promote a token, including $TAPE.

Maintainers can edit, hide or lock anything that breaks this, and block repeat offenders. To raise a problem privately, use a GitHub security advisory on this repository.
