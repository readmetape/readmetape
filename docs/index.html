01, THE CARD

        
one card, everything a holder checks first.

        
logo, symbol, chain and DEX, price, the change over 24h or 7d, a real chart from GeckoTerminal candles, market cap, liquidity and 24h volume. drawn as a plain SVG, so GitHub shows it as is.

        
no scripts, no external requests, the token logo inlined as a data URI. GitHub's image proxy has nothing to block.

02, THE ACTION

        
a GitHub Action keeps it fresh.

        
drop in the workflow and run it once. it rewrites .github/tape.svg on your schedule and only commits when a number on the card moved. a new timestamp alone never makes a commit.

        
.github/workflows/tape.yml


name: tape
on:
  schedule: [{ cron: '*/30 * * * *' }]
  workflow_dispatch:
permissions:
  contents: write
jobs:
  tape:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: OWNER/tape@v1
        with:
          tokens: YOUR_TOKEN_ADDRESS
          theme: cream
          label: paid to dev

      

      

        
Three steps

        
    
          
  1. add the workflow above as .github/workflows/tape.yml and set your token address.
    2. 
          
  2. run it once from the Actions tab so .github/tape.svg exists.
    3. 
          
  3. put ![$COIN](.github/tape.svg) in your README, linked to the chart if you like.

04, QUESTIONS

    
the short answers.

    

      
do I need an API key?
no. DexScreener and GeckoTerminal both have free public endpoints. tape retries with backoff on rate limits and can keep chart data in a small cache file.

      
will GitHub show the token logo?
yes. the logo is downloaded at render time (96 KB max) and inlined as a data URI. no usable logo means a monogram.

      
how fresh is the data?
as fresh as your schedule. GitHub runs scheduled workflows best effort, so a 30 minute cron can run late when GitHub is busy.

      
which chains work?
any chain DexScreener has prices for. charts work where GeckoTerminal has the pool: Solana, Ethereum, Base, BSC and more.

      
why readme-tape on npm?
tape on npm is a long-running test runner. the package is readme-tape, the command it installs is tape.

      
is this financial advice?
no. tape shows public market data in a README. do not trade off it.
